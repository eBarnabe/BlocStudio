        Double-cliquez dessus pour le lancer. Vous pouvez le copier sur une clé USB ou l'envoyer à vos amis.

      
Votre programme est enregistré ici :

      
Double-cliquez dessus pour le lancer, comme n'importe quel logiciel.
        Vous pouvez le copier sur une clé USB ou l'envoyer à vos amis.

      

        ⚠️ Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur ».
        C'est normal pour un programme que l'on vient de créer soi-même (il n'est pas « signé » par un éditeur connu) :
        cliquez sur Informations complémentaires, puis sur Exécuter quand même.
      

      

        🔒 Message « Vos paramètres de sécurité Internet ont empêché l'ouverture… » ?
        Faites un clic droit sur le fichier → Propriétés → en bas, cochez Débloquer → OK.
        Le programme s'ouvrira ensuite normalement (à faire une seule fois par fichier).
      

      
Fonctionne sur Windows 10 et 11. Le navigateur peut aussi demander de confirmer
        le téléchargement d'un fichier .exe : choisissez « Conserver ».

      
Fonctionne sur Windows 10 et 11. Sur un autre ordinateur, Windows peut afficher
        « Windows a protégé votre ordinateur » : cliquez sur Informations complémentaires → Exécuter quand même.
